# Skiko Fork

`skiko/` is the complete Skiko repository tracked as a submodule. It already contains the experimental `skiko-graphite` Gradle module at:

```text
skiko/skiko/skiko-graphite/
```

The local submodule has two remotes:

- `origin`: `https://github.com/rafambn/skiko.git`
- `upstream`: `https://github.com/JetBrains/skiko.git`

Graphite changes belong in the Skiko fork. The Compose wrapper belongs in the sibling `graphite-surface` project.
